# Recorded EggBert captures

These are real `EGG1` captures collected with EggBert. Open the [EggBert Capture Viewer](../) in Chrome or Edge and choose one from **Load sample**, or download a file directly:

- `throw-catch-4ft.egg` — four-foot throw and catch.
- `drop-2in-silicone-pad.egg` — two-inch drop onto a silicone pad.
- `drop-5in-hard-foam.egg` — five-inch drop onto hard foam.
- `drop-twirl-short-string.egg` — drop and twirl on a short string.
- `drop-twirl-long-string.egg` — drop and twirl on a long string.

Every file contains 19,200 XYZ samples at 3,840 Hz, uses the current ±16 g scale, and has a valid CRC. The viewer plots X, Y, Z, and vector magnitude, and estimates flight time and peak height when it finds a sustained freefall followed by a substantial impact.
