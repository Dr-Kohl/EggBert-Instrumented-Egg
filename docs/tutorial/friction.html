EggBert menu: HOME 1 → FRICTION

Current controls

  1. Start with the ramp low and press middle to arm.
  2. Set EggBert down during AUTO ARM. At TILT SLOW, increase the angle slowly until it slides.
  3. Read the trial angle, MU and average. Middle starts another trial; bottom opens the trial list.

In the list, top/bottom select a trial, REARM or EXIT. Middle deletes the selected trial or chooses REARM/EXIT. Up to five trials are retained.

Top: return HOME from idle or result. Middle: stop while armed. Friction uses low-g on both versions.
