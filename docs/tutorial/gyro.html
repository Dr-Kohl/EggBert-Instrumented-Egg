EggBert menu: HOME 1 → GYRO

Current controls

  1. Hold EggBert still while it settles and zeros.
  2. Rotate it, then stop to read the signed peak on each axis in degrees per second.

Top: switch PEAK/LIVE. Middle: reset the peak and briefly hold still. Bottom: return HOME.

The gyro operates the same way on V1 and V2.
